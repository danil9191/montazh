Разговорные ролики

Человек говорит в камеру. Моя работа — чтобы это досмотрели: темп, субтитры, карточки с цифрами, наезды.

Нарезки из подкастов

Из часового выпуска достаю моменты, которые работают сами по себе. Вертикальный кадр, субтитры по словам, заголовок, музыка под настроение, в конце ссылка на полный выпуск. Эти три собраны из открытых выпусков как образец, авторы не мои клиенты.

Ролики без съёмки

Камера не нужна. Из текста собираю историю: картинки, анимация, озвучка, субтитры. Эти четыре сделаны для программы Sunlight.

Как работаем

  1. Присылаете видеоВ Telegram или ссылкой на облако. Можно как сняли, с дублями и оговорками.
  2. Утром ролик у васМонтирую, пока в Москве ночь. Один ролик — к следующему утру.
  3. ПравкиПишете, что поменять. Правлю в тот же день, без доплат.
  4. Дальше по вашему стилюШрифт, цвета и плашки запоминаю. Следующие ролики выходят в одном виде.
